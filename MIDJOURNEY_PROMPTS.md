## Additional Style Notes for All Prompts

**Key Elements to Emphasize:**
- **Tree**: Delicate, growing, positive, with pink blossoms
- **Fruits**: Cherry (red), Watermelon (green), Orange, Pineapple (yellow), Grape (purple)
- **Bubbles**: Translucent, floating, playful
- **Colors**: Soft pastels - pink, coral, lavender, mint green, peach
- **Mood**: Calming, positive, gentle, uplifting, peaceful
- **Style**: Modern, minimalist, clean illustration

**Technical Parameters:**
- Use `--style raw` for more natural, less stylized results
- Use `--v 6` for latest Midjourney version
- Adjust aspect ratios as needed: `--ar 1:1` (icon), `--ar 2:1` (banner), `--ar 9:16` (background)
- Consider adding `--stylize` parameter (250-750) to control artistic interpretation

**Refinement Tips:**
- If results are too busy, add "minimalist" or "clean design"
- If colors are too vibrant, add "soft pastel" or "muted tones"
- If tree is too prominent, add "subtle" or "in background"
- For more bubbles, add "multiple floating bubbles" or "bubble pattern"
